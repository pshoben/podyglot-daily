Podyglot Today feed

Daily news, weather and sport bulletins for language learners, one static JSON file per programme. This is a machine feed the Podyglot app reads; it is published so an edition can reach a listener without waiting on an app release.

Convention

channels.json lists every channel. daily/<dialect>/index.json is one channel's episode list, newest first. Each entry carries the file to fetch alongside it, its bytes and its sha256. The same folder's index.html is the same list, to read.

The episode files are byte-identical to the ones inside the app.
